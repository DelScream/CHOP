# CHOP / CLOSED PERIMETER

Концепт цифрового штаба частной охраны: графит и сталь, схема объекта, посты и периметр, дисциплина диспетчерской. B2B-безопасность как контур контроля, а не «человек в форме у двери».

**Автор:** Валерий Гацкан ([@DelScream](https://github.com/DelScream))  
**Демо:** [delscream.github.io/CHOP](https://delscream.github.io/CHOP/)
